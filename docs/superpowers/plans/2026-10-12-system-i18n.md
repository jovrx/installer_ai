# System bilingual configuration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver configurable Chinese/English across A Web, B GUI/TUI/plain, and Controller/MCP command-line messages.

**Architecture:** Shared embedded JSON translation resources and typed Go locale/configuration service; browser imports the same resources. Structured state/error facts are rendered in the selected language instead of translating previously formatted Chinese strings. Locale remains local and never changes task authority.

**Tech Stack:** Existing Go/Vue/Win32/Bubble Tea; no new runtime framework or dependency.

**Spec:** docs/superpowers/specs/2026-10-12-system-i18n-design.md

## Global Constraints

- Languages `zh-CN` and `en-US`; default `zh-CN`. API enum values, JSON fields, task signatures, scope/approval, MCP names and arguments remain stable.
- Priority `--lang` > `REMOTEOPS_LANG` > explicit `--config` file > saved current-user settings > Chinese. Explicit settings are validated even when overridden; implicit unreadable/corrupt settings fall back with a recoverable warning.
- Default paths: os.UserConfigDir()/RemoteOps/{worker,controller,mcp}-settings.json. JSON is exactly language settings, no credentials. UI saves to explicit config if provided, otherwise default path. CLI/env overrides do not silently save.
- Each side has independent preference. Browser stores only its own language; Windows UAC/external logs/software and device names remain original.
- Runtime switches preserve tasks/selection/log reading; preconnection switching clears unsubmitted consent/key. No language shortcut/command interpretation during masked key input. Ctrl+C stays immediate.
- Worker helper dispatch happens before settings or UI, rejects mixed language/config/UI/pairing arguments.
- Ordinary-user communications; CGO_ENABLED=0; no WebView2; real download bytes and indeterminate install progress unchanged; default20/history100 and active retention preserved.
- Test-only inert fixtures; no real sessions/install/UAC decisions, no stop/start of existing instances. Tests isolate preferences via temporary config directories.
- Main's preexisting changes are snapshotted only on isolated branch (7ea06c3). Final integration applies feature diff after that snapshot to current main working tree without committing or reverting user baseline.
