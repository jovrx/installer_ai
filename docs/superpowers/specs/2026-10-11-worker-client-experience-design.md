# B 端客户端 GUI / TUI 设计

状态：用户已确认，可实施。用户已选定独立 Windows 桌面窗口；本轮暂不执行真实软件安装验收。

## 目标

B 用户能够通过桌面窗口或终端完整完成配对、查看并同意授权、连接、观察执行进度、取消当前任务和主动断开。两种界面使用同一连接与执行逻辑，所有用户提示默认中文。

支持 Windows 10/11 x64 普通用户运行，延续便携式交付，不注册服务或开机启动。

## 方案选择

| 方案 | 收益 | 代价 | 结论 |
| --- | --- | --- | --- |
| Go + Windows 原生窗口 + 终端 TUI | 无额外浏览器运行时，保留无 CGO 构建与便携交付 | 需要处理窗口消息、布局及 DPI | 采用 |
| WebView2 桌面窗口 + TUI | 可复用 Web 样式，复杂布局开发方便 | Windows 10 设备可能缺少 WebView2 Runtime | 本轮不采用 |

桌面窗口通过现有 golang.org/x/sys/windows 调用 Windows 窗口 API，采用原生输入框、密码框、文件选择、按钮与键盘焦点；状态卡片、阶段条和进度区域使用统一绘制与布局。不依赖用户另外安装运行时。

终端采用成熟的 Go TUI 库处理输入、屏幕重绘、窗口变化和 ANSI 样式。配色以深蓝、青绿为主，警告用暖黄，错误用红色；同时提供文字标签，不能仅靠颜色区分状态。

## 启动与交付

- 新增 `remoteops-worker-gui-windows-amd64.exe`：双击打开桌面窗口，无额外命令窗口；可选 `--pairing` 预填配对文件。
- 保留 `remoteops-worker-windows-amd64.exe`：默认进入 TUI；支持 `--ui=tui` 和 `--ui=plain`。旧 `--pairing 文件.json` 命令继续有效。
- 两个入口共用同一客户端应用层；GUI EXE 使用 Windows GUI subsystem 构建。
- plain 模式用于终端兼容与诊断，仍提供中文阶段信息。非交互环境不能跳过本地授权，不能从命令行参数传入 Auth Key。
- 内部 elevated-helper 必须在任何界面初始化前处理，不能打开第二个主窗口或进入 TUI。
- `scripts/build.mjs` 增加 GUI 产物及摘要；不替换运行中的 Controller/Worker。

## 界面与用户流程

### 连接前

桌面版用三步流程：选择配对文件 → 核对授权 → 同意并连接。显示控制方名称与地址、允许的软件及固定版本、允许的任务类型、管理员权限、配对截止和授权时长。授权必须明确确认，Auth Key 为遮罩输入，提交后及时清空。

终端版提供对应步骤和醒目的授权摘要；支持粘贴配对文件路径。路径与密钥输入不能和屏幕重绘竞争；Auth Key 始终不可见，不回显、不写入日志。

错误提示包含简明原因和可执行的下一步，例如“配对文件已过期，请向控制方获取新的文件”。失败不自动反复使用单次凭据；注册完成后的断开需要新会话及新凭据。

### 连接后桌面布局

```text
RemoteOps · 临时远程协助                      已连接
控制方：我的控制端             剩余授权：42 分 10 秒

当前任务                              Git 2.51.0
正在下载安装包，请稍候
[████████████░░░░░░░░] 下载 62% · 38.3 / 61.7 MB

下载 → 校验 → 等待权限确认 → 安装 → 版本验证
已用时间 00:24                 [取消当前任务]

本次授权    检查系统 / 安装 Git / 可请求管理员权限
最近任务    系统检查已完成 · Git 正在下载
详细日志    默认收起，按需展开

你可以随时结束本次协助                  [立即断开]
```

上面的进度数值仅用于设计示意。生产界面只能显示执行器实际报告的值。

窗口使用清晰的卡片分区、留白、圆润视觉元素和轻量状态图标。等待时使用温和文案，如“已连接，等待控制方安排任务”“请在 Windows 权限窗口中确认后继续”。空闲页不呈现原始 JSON。

### 终端布局

```text
╭─ RemoteOps · 临时远程协助 ───────────────────────╮
│ ● 已连接    我的控制端     授权剩余 42:10        │
├──────────────────────────────────────────────────┤
│ 当前任务  Git 2.51.0                             │
│ 下载中    ████████████░░░░░░░░ 62%               │
│ 38.3 / 61.7 MB                 已用 00:24         │
│ 下载 → 校验 → 权限确认 → 安装 → 版本验证         │
├──────────────────────────────────────────────────┤
│ 最近任务 / 可展开的详细日志                      │
╰──────────────────────────────────────────────────╯
  L 日志    C 取消当前任务    D 断开    ? 帮助
```

终端支持中文显示宽度计算、窄窗口重新排版和无彩色模式。Escape 返回或关闭日志；D 发起断开并确认，Ctrl+C 立即断开并退出，不能因确认弹窗延迟应急退出。输入密钥时上述任务快捷键不生效。

### 任务与结束

当前任务区优先显示执行中的任务，其次排队任务；并发任务以独立卡片或列表表示，禁止将多个任务的进度混在一起。任务按时间稳定排序，默认显示最近 20 项，按需查看最多 100 项的本地历史视图，不增加磁盘历史存储。

取消作用于选中的当前会话任务；明显区分“取消任务”和“断开整个会话”。提示已经发生的安装变更不会自动回滚。

成功页显示软件、验证版本和是否需手动重启；失败页显示脱敏原因和下一步；关闭、授权到期和心跳失联显示不同结束原因。GUI 关闭窗口即结束会话，不后台静默保留连接。结束后窗口可保留结果摘要，提供重新选择配对文件与退出按钮。

## 共享应用层

从 cmd/worker/main.go 提取生命周期服务，负责配对校验、本地同意、tsnet 连接、注册、RPC、本地任务查询与断开。GUI/TUI 仅通过受控命令调用服务并订阅只读快照，不直接操作凭据和 RPC 权限。

共享快照包含连接阶段、控制方、授权摘要、剩余时间、最近任务、任务进度、结果与脱敏日志。状态更新使用有界队列或合并快照，不能让慢界面阻塞安装线程。所有任务状态并发访问必须加锁或复制。

推荐文件边界：

- `internal/worker/client/`：生命周期、视图模型、状态订阅和中文提示。
- `internal/worker/ui/tui/`：终端表单、卡片、快捷键与纯文本降级。
- `internal/worker/ui/gui/`：Windows 窗口、文件选择、布局、DPI、绘制与事件分发。
- `internal/worker/progress.go`：Worker 本地任务进度及脱敏快照。
- `cmd/worker/`：参数、UI 模式选择与 helper 分流。

现有本地浏览器状态接口可继续作为诊断入口，默认启动不再自动打开浏览器。接口沿用本地随机令牌及 Origin 检查，不向 tailnet 暴露。

## 真实进度采集

定义内部结构化执行事件：task_id、阶段、用户提示、已下载字节、可信总字节（可空）、时间。事件和诊断日志分别保存，UI 不解析自然语言日志猜测阶段。

阶段包含 queued、inspecting、downloading、verifying_artifact、awaiting_uac、installing、verifying_version 和终态。取消中单独显示；断开或终态必须覆盖迟到的进度事件，不能被后续消息改回执行中。

下载以网络实际接收字节报告进度；总大小取可信的实际 Content-Length。目录 size_bytes 是大小上限，不可拿来当实际总量。无总大小时显示已下载量和不定进度。现有大小上限、下载来源校验、取消和 SHA-256 校验必须继续生效。

安装器没有可靠百分比时显示“正在安装”、不定进度、已用时间和最近活动；不能制造安装总百分比或预计完成时间。进程结束后仍需通过版本验证，才显示成功。

需要提权时，先显示明确的 UAC 提示，再启动 helper。现有 helper 只在结束后返回日志，必须增加经过本地 proof 验证、限制大小与消息类型的实时事件通道；事件不能携带执行命令或扩大原有提权请求范围。通信程序始终普通权限。

首版进度信息服务 B 本地 UI，不要求调整 Controller/Worker 的远程 TaskSpec、审批摘要或任务调度契约。现有 Executor 测试替身可通过兼容适配器继续工作。

## 验收

1. GUI 双击启动无命令窗口；无配对参数可选择文件；CLI 原命令有效，默认 TUI。
2. 两套界面完整呈现授权并要求本地同意；密钥隐藏，错误有中文提示，未同意不联网。
3. 使用惰性测试执行器模拟下载、校验、UAC 等待、安装与版本验证，验证状态切换、真实字节比例、未知总量、不定安装进度和多任务隔离。模拟场景明确标注，不能伪装真实安装。
4. 验证取消、断开、授权到期和失联；终态不可被迟到事件覆盖；UI 不阻塞任务退出。
5. 覆盖 helper 实时事件认证、大小限制、取消传播、日志脱敏及普通权限边界。
6. GUI 验证键盘操作、最小 720×560 窗口、100%/150%/200% DPI；TUI 验证至少 60×18 与 100×30、中文宽度及窗口变化。
7. Go 单元与集成测试、race、vet 通过；构建两套 Windows EXE 并校验摘要。
8. 本机实际打开 GUI 和 TUI，验证配对错误、拒绝授权和模拟任务进度；不进行用户暂缓的真实安装/UAC决策，也不重启当前已连接的 B。

## 本轮不增加的功能

不加入系统服务、自动重连、长期凭据保存、自动审批、自动重启、远程桌面或任意命令执行。托盘驻留和跨会话历史留待后续需求。
