# 真实环境验收

以下项目必须由真实环境验证。单元测试、模拟 Worker 和交叉编译不能证明其已经通过。本轮开发未提供 tailnet 凭据、异地设备或 Windows 10/11 测试机，因此初始状态统一为未实测。

| 场景 | 验证步骤 | 通过标准 | 状态 |
|---|---|---|---|
| 单 EXE | 全新 Windows 10/11 x64，无官方 Tailscale/OpenSSH，启动 Worker | 仅本 EXE 即可出现授权说明并连接 | 未实测 |
| 本地授权 | 输入配对包、查看控制方/期限/软件/管理员范围，先拒绝后同意 | 拒绝不连接，同意后才注册 | 未实测 |
| 跨 NAT | A/B 位于不同内网，查询系统信息 | 通过 tsnet 返回环境和可靠状态 | 未实测 |
| 软件安装 | 配置真实 pinned MSI/Git 来源与摘要，经 Web 审批后安装 | 输出、退出码和实际版本验证一致 | 未实测 |
| UAC 拒绝 | 普通权限启动，批准需要管理员权限的软件，再拒绝 UAC | permission_denied，没有尝试绕过 | 未实测 |
| UAC 批准 | 本地批准 UAC | 只有受控 helper 提权，通信 RPC 仍普通权限 | 未实测 |
| 取消与超时 | 取消运行中的测试安装，测试期限届满 | 受控进程树终止；清晰表示不保证回滚 | 未实测 |
| A/B 断开 | 两端分别主动终止会话 | 新任务被拒绝，B 清除临时身份 | 未实测 |
| 断线/崩溃 | 强杀 Worker 或断网，等待心跳 TTL | 应用授权撤销、结果不明安装不自动重放 | 未实测 |
| 节点清理 | 测试有效/无效删除权限 | 成功显示 closed；失败可见并可重试 | 未实测 |
| ACL 隔离 | B1 尝试连 B2 和 A 管理端口 | tailnet 策略拒绝 | 未实测 |
| 身份重建 | 三个临时 B 顺序接入，同机再次接入新会话 | 无旧会话继承与设备混淆 | 未实测 |
| 多设备 | 3～10 台设备连接，配置并发上限 | 无超并发、重复执行及日志内存失控 | 未实测 |
| Controller 重启 | 执行中重启 A，查询同任务 ID | 恢复/unknown 状态明确，不重复安装 | 未实测 |
| A 跨平台 | macOS/Linux 启动 Controller + 官方 Tailscale | Web/MCP/WhoIs 及 Worker 调度可用 | 未实测 |
